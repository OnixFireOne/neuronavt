## Коротко
Talorys — бесплатный open-source персональный помощник, который разворачивается в аккаунте Cloudflare и объединяет чат, память, задачи, заметки и напоминания. Данные остаются в инфраструктуре пользователя, а приложение рассчитано на бесплатные квоты Cloudflare, но AI-чат зависит от дневного лимита Workers AI.

## Контекст
В статье представлен Talorys — проект для одного пользователя, созданный для запуска персонального AI-агента без отдельного сервера и без аккаунтов или инфраструктуры, управляемых разработчиками Talorys. Проблема исходного подхода — необходимость самостоятельно собирать чат, хранение данных и планировщик; автор предлагает развертывание одной командой в собственном Cloudflare-аккаунте.

## Главное
- Установка выполняется одной командой: `npx create-talorys@latest`; требуется Node.js 20.18+.
- Приложение рассчитано на одного владельца: без регистрации, команд и учетных записей Talorys; пароль задается при установке.
- Архитектура: React-приложение на Cloudflare Pages → Pages Function → приватный Worker через service binding → `TalorysAgent` на Cloudflare Agents SDK Durable Object.
- Worker использует Hono; Durable Object хранит SQLite с беседами, памятью, задачами, заметками, проектами, автоматизациями, сессиями, настройками и данными использования.
- Модель чата — `@cf/zai-org/glm-4.7-flash` через Workers AI; потоковые ответы поддерживают Server-Sent Events и вызовы инструментов.
- Память содержит личные факты и предпочтения, которые можно просматривать, менять и удалять; в запрос модели включаются только наиболее релевантные записи.
- Напоминания и повторяющиеся расписания запускаются через Durable Object alarms; доступны ежедневные дайджесты задач и необязательные AI-рутины.
- Приложение заявлено как работающее на бесплатных тарифах Pages, Workers, Durable Objects (SQLite) и Workers AI; AI использует дневную квоту.
- Инсталлятор проверяет развертывание без запуска AI-инференса; повторный запуск после сбоя согласует уже созданные ресурсы, не создавая дубликатов и не удаляя данные.
- Есть экспорт и импорт `talorys-backup.json`, автоматические миграции схемы и команды `update`, `status`, `doctor`; сброс пароля отзывает все сессии.

## Как сделано
Установка запускается командой `npx create-talorys@latest`; требуется Node.js 20.18+. Инсталлятор авторизуется через Wrangler OAuth или токен Cloudflare, создает приватный Worker и Pages-проект, задает пароль владельца, сохраняет его хеш как Cloudflare secret и проверяет доступность развертывания. Для неинтерактивного режима предусмотрены `TALORYS_OWNER_PASSWORD=... npx create-talorys@latest --yes --account-id <id>` и `CLOUDFLARE_API_TOKEN`.

Браузер обращается к сайту `*.pages.dev`, а Pages Function проксирует `/api/*` через service binding к Worker без публичного URL (`workers_dev: false`, `preview_urls: false`). Worker использует Hono и Cloudflare Agents SDK Durable Object `TalorysAgent`; данные хранятся в SQLite внутри Durable Object. Для чата применяется Workers AI с моделью `@cf/zai-org/glm-4.7-flash`, ответы передаются потоково через Server-Sent Events. Alarms Durable Object запускают напоминания и расписания; простые напоминания и сводки задач не требуют AI.

Локальный запуск: `git clone https://github.com/rociiu/talorys.git`, затем `npm install` и `npm run dev`. В разработке используется детерминированный mock AI, локальный пароль по умолчанию — `talorys-dev-password` (можно задать `TALORYS_DEV_PASSWORD`). Обновление развертывания выполняется командой `npx create-talorys@latest update`.

## Результаты
По описанию, пользователь получает частного однопользовательского помощника с потоковым чатом, редактируемой долговременной памятью, CRUD для задач, заметок и проектов, а также одноразовыми и повторяющимися напоминаниями, уведомлениями и опциональными AI-рутинами. Все основные сервисы заявлены как совместимые с бесплатным тарифом Cloudflare; дополнительные R2, D1, KV, Vectorize, AI Search, Workflows и платные сервисы не подключаются. Данные хранятся в аккаунте пользователя, а проект заявляет отсутствие телеметрии и рекламного или аналитического трекинга. В статье нет результатов независимого тестирования, численных показателей качества или производительности.

## Ограничения
Бесплатность не безлимитна: действуют квоты Cloudflare на запросы, Durable Objects и дневную аллокацию Workers AI, которые могут измениться. При исчерпании AI-квоты чат приостанавливается до дневного сброса, хотя задачи, заметки, память и напоминания продолжают работать; на платном аккаунте сверх включенных лимитов возможна тарификация Cloudflare. Cloudflare обрабатывает данные для предоставления услуг, включая сообщения чата и попавшие в промпт релевантные воспоминания. Авторский текст описывает архитектуру и функции, но не приводит независимую оценку безопасности, надежности, качества модели, фактического потребления квот или затрат на разных сценариях.

## Что взять себе
- Можно развернуть персонального агента в собственном Cloudflare-аккаунте, не поднимая сервер и базу данных отдельно.
- Разделение обычных функций и AI полезно: задачи и простые напоминания остаются доступными даже при исчерпании квоты модели.
- Перед использованием стоит проверить политики Cloudflare: данные не отправляются разработчикам Talorys, но Cloudflare обрабатывает сообщения и AI-запросы.
- Оцените квоты и потенциальную тарификацию своего аккаунта: обещание бесплатного тарифа не означает неограниченного использования.
- Для личного проекта предусмотрены экспорт данных, восстановление после прерванной установки и перенос обновлений без пересоздания хранилища.
