## Коротко
Автор за сутки собрал с Claude Code открытое приложение для Mac, которое записывает речь, превращает её в заметки и задачи и показывает лимиты Claude; особенно полезны его уроки о резервной записи и проверках от тихих сбоев.

## Контекст
Автор рассказывает, как сделал для себя Андреича — помощника, уже работавшего у него по телефону, на сайте и в Telegram. Новое приложение для macOS помещает енота в экранный вырез и связывает голосовые заметки с сессиями Claude Code.

## Главное
- Речь распознаётся локально, но приложение дополнительно сохраняет исходный звук: если распознавание тихо остановится, разговор можно восстановить.
- Распознавание нужно перезапускать аккуратно: старую задачу отменяют перед созданием новой, а отдельная проверка следит за отсутствием текста при наличии звука.
- Модель предлагает задачи по протоколу, но не запускает их сама: отправка в сессию Claude Code требует подтверждения в Telegram.
- Приложение также ведёт заметки, создаёт напоминания, делает сводки, показывает расход лимита и хранит перетаскиваемые файлы.

## Как сделано
Приложение написано на Swift и JavaScript и опубликовано под лицензией MIT. Для выреза используется обычное окно без рамки поверх строки меню. Русскую речь распознаёт системный SFSpeechRecognizer с requiresOnDeviceRecognition, а звук параллельно сохраняется в m4a. Запрос распознавания перезапускается каждые 50 секунд, перед запуском нового старая задача отменяется. Проверка раз в 0,4 секунды выявляет случай, когда звук есть, а результатов нет дольше 15 секунд; после трёх таких сбоев движок перезапускается. Раз в пару минут свежий текст и список сессий передаются в claude -p --model haiku для создания карточек. Задачу в Claude Code приложение отправляет только после подтверждения владельца в Telegram. Для файлов во время перетаскивания создаётся временное невидимое окно-ловушка. Доступны macOS 14+ и Swift из Command Line Tools; для сборки 3D нужен Node.js.

## Результаты
Первая версия потеряла почти весь часовой разговор: в протокол попали только пять строк первой минуты. После исправлений приложение пишет звук примерно по 20 МБ в час. В покое 3D-енот использует 2–3% одного ядра и около 90 МБ памяти. Первая версия приложения была опубликована через сутки; в ней около 4 900 строк кода.

## Ограничения
SFSpeechRecognizer может перестать выдавать результаты без ошибки, поэтому автор добавил контроль и резервную запись. Текст для карточек и сводок отправляется в Claude Code; аудио остаётся на диске. Получение лимитов использует недокументированный адрес и может перестать работать. Для карточек и сводок нужны установленный Claude Code и подписка. Нет активации голосом по имени и голосовых ответов; без Claude Code остаются протокол и файловая полка. Требуется macOS 14+, а 3D-сборке — Node.js.

## Что взять себе
- Для голосовых инструментов сохраняйте исходное аудио, а не полагайтесь только на расшифровку.
- Проверяйте не только ошибки, но и признаки тихого отказа: например, звук идёт, а текст долго не появляется.
- Просите явного подтверждения перед тем, как распознанная речь изменит код или запустит действие.
- Если делаете приложение поверх необычной части интерфейса macOS, проверяйте поведение при конфликте с другими приложениями.
