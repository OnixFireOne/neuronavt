## Коротко
Codemode позволяет AI-агентам писать небольшой код, чтобы объединять и параллельно выполнять вызовы инструментов, не перегружая контекст. Это полезно разработчикам и тем, кто настраивает агентов, но подход пока имеет ограничения.

## Контекст
Автор Pi объясняет, почему после прежнего совета предпочитать CLI и скрипты команда добавила поддержку MCP через Codemode в Pi 1.0. Проблема: bash хорошо комбинирует исполняемые программы, но не может напрямую вызвать некоторые возможности обвязки агента, например чтение изображений, субагентов или API моделей.

## Главное
- Codemode переносит составление рабочих цепочек вызовов в обвязку агента: модель пишет код, который вызывает инструменты и обрабатывает ответы.
- Это дополняет, а не отменяет CLI и bash: они по-прежнему удобны для программ и файлов, но некоторые функции доступны только через обвязку агента.
- Через Codemode можно обращаться к API моделей для генерации изображений и классификации, не добавляя отдельный инструмент для каждой задачи.
- Для MCP особенно важны структурированные JSON-ответы, одинаковый формат данных и удобный поиск подходящих инструментов.

## Как сделано
Codemode запускает JavaScript внутри обвязки агента, в отдельной песочнице QuickJS на WASM. У неё нет доступа к сети и файловой системе, нет таймеров и ограничена память; взаимодействовать с внешним миром можно только через инструменты. Код позволяет объединять вызовы, выполнять независимые операции параллельно и сохранять результаты между вызовами одной сессии. В Pi Codemode по умолчанию включается вместе с MCP; отдельно его можно активировать настройкой "defaultTools": ["+codemode"]. Примеры в статье: генерация изображений, классификация GitHub Issues моделью Jev и вызовы MCP-сервера Sentry.

## Результаты
В примере с GitHub Issues агент получает до 100 открытых задач, классифицирует их и выводит до 12 задач с наибольшей оценкой раздражения. Pi ограничивает одновременное выполнение вызовов инструментов четырьмя, а остальные ставит в очередь. Других измеренных результатов автор не приводит.

## Ограничения
Codemode не обеспечивает лёгкого восстановления после сбоев; автор рассматривает сохранение снимков состояния и более детерминированный язык вроде Starlark. MCP-серверы часто возвращают неструктурированные или непоследовательные данные, плохо поддерживают большие бинарные данные, а поиск инструментов сразу по нескольким серверам трудно масштабировать. Вложенный Codemode усложняет код экранированием JSON и может сбивать небольшие модели. Это пока не идеальное решение.

## Что взять себе
- Используйте Codemode, когда нужно связать несколько вызовов или обработать много результатов в одном процессе.
- Для обычных команд и файлов CLI и bash остаются простым и понятным выбором.
- Проверяйте структуру ответов MCP на малых и больших выборках, прежде чем запускать обработку целиком.
- Не считайте песочницу Codemode целевой средой: автор подчёркивает, что она работает внутри обвязки агента, за отдельной границей доверия.
