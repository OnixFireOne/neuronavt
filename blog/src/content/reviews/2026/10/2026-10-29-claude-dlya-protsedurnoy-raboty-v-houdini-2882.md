## Коротко
Автор показывает, как подключить Claude к Houdini через MCP и hython: это помогает создавать процедурные сцены и выполнять рутину, если агенту ясно задавать шаги и проверять его работу.

## Контекст
Автор регулярно тестирует ИИ-агентов, потому что без доступа к самому Houdini они менее полезны. В статье он описывает настройку панели в Houdini, проблемы на Windows и собственный рабочий способ через hython.

## Главное
- Панель MCP позволяет общаться с Claude прямо внутри Houdini, но настройка на Windows может потребовать исправлений.
- Подробные пошаговые указания помогают получить понятную сеть нод, которую можно редактировать, а не скрытый скрипт.
- Для задач без необходимости работать в интерфейсе автор предпочитает hython: агент создаёт и запускает скрипты Houdini.
- Автор считает агентов особенно полезными для рутины, например массового назначения материалов, но советует проверять их действия.

## Таблица
| Симптом | Причина или решение |
| --- | --- |
| 401 OAuth access token has expired после setx | Агент использует старый вход из ~/.claude/.credentials.json; проверить токен командой claude -p "reply with: ok" |
| Houdini не видит переменную после setx | Перезапустить Проводник или выйти из Windows |
| 401 сохраняется | Исправление MAY4VFX/houdini-agent-panel#46: читать HKCU\Environment |
| Агент отвечает, но не видит инструменты Houdini | Исправление MAY4VFX/houdini-agent-panel#47; вручную добавить пути pywin32 в HAP_MCP_PATH |

## Как сделано
Для чата внутри Houdini автор использует панель houdini-agent-panel (MIT) с MCP-сервером fxhoudinimcp. Установка: `uvx --from houdini-agent-panel python -m houdini_agent_panel install`, затем перезапуск Houdini и выбор Agent через «+» → New Pane Tab Type. Для входа по подписке Claude Pro/Max без API-ключа используются `claude setup-token` и `setx CLAUDE_CODE_OAUTH_TOKEN "sk-ant-oat01-…"`.

На Windows автор столкнулся с устаревшими учётными данными, обновлением переменных окружения и сбоями MCP из-за pywin32. Для исправлений он указывает MAY4VFX/houdini-agent-panel#46 и #47; ручной обход для pywin32 — добавить `deps\py3.13\win32` и `win32\lib` в HAP_MCP_PATH в `Documents\houdini22.0\packages\houdini_agent_panel.json`.

В обычной работе автор чаще запускает Houdini без интерфейса через hython — Python с модулем hou. Агент пишет скрипт и запускает его командой `& "C:\Program Files\Side Effects Software\Houdini 22.0.368\bin\hython.exe" build_scene.py`. Для сцены жеоды автор просил создавать ноды по одной, держать сеть видимой, подписывать и раскрашивать этапы, проверять результат скриншотом и исправлять ошибки, а не начинать заново.

## Результаты
В демонстрации жеоды Claude собрал сеть из 31 ноды примерно за 22 минуты; видео было ускорено примерно в 24 раза. В другом случае агент назначил много материалов в Karma, но точное количество автор не помнит.

## Ограничения
Агент может ошибаться и без указаний собрать сцену в малом числе нод с кодом на Python, что затрудняет редактирование. На Windows панель и MCP могут не заработать без исправлений. Автор предупреждает: подключённый агент может выполнять любой Python в Houdini, поэтому использовать его следует только на своей рабочей машине. Каждое действие можно отменить отдельно через undo.

## Что взять себе
- Разбивайте задачу на этапы и просите агента создавать отдельные ноды с понятными именами.
- Требуйте проверки результата после каждого этапа и исправления ошибок на месте.
- Для автоматизации без интерфейса рассмотрите hython; для общения внутри Houdini — MCP-панель.
- Не подключайте агента к важной рабочей машине без понимания, что он может выполнять Python-код.
