## Коротко
Менеджер продукта без опыта разработки собрал на Python монитор, который отслеживает наличие АИ‑95 на выбранных АЗС и присылает уведомления. Инструмент помог автору заправиться без очереди, а проект также сохраняет историю статусов и показывает заправки на карте.

## Контекст
Автор — Игорь, менеджер продуктов Outlines Tech. После нескольких многочасовых ожиданий за АИ‑95 он хотел получать сведения о топливе на ближайших заправках, включая Роснефть и Teboil. Сначала он искал готовый сервис через ChatGPT, но решил сделать собственный монитор, чтобы получать уведомления без подписки на новые Telegram-каналы.

## Главное
- Автор — Игорь, менеджер продуктов Outlines Tech; до проекта он самостоятельно ничего не разрабатывал.
- Монитор предназначен для АИ‑95 на выбранных АЗС, в том числе Роснефти и Teboil; за ориентир по функциям автор взял сервис «ГдеБЕНЗ».
- ChatGPT сначала предложил PetrolPulse, а затем помог сформулировать вариант собственного парсера.
- По словам автора, публичной документации API о наличии топлива у Яндекса и Т-Банка найти не удалось; вместо этого ИИ предложил изучить загрузку данных сайтами.
- Код написан на Python с помощью Codex; монитор запущен на Android через Termux.
- Проверка выполнялась каждые 10–15 минут, а уведомления отправлялись через Pushover.
- Сообщение содержало название и адрес АЗС, сведения о наличии топлива из каждого источника и время обновления.
- Через неделю автор добавил историю статусов с фильтрацией по заправке и источнику; примерно через месяц — браузерную карту на MapLibre.
- Вероятные часы подвоза рассчитываются по истории времени, когда источники сообщали о появлении бензина; приведённый пример для Роснефти на Волгоградском проспекте — 5:00, 6:00 и 11:00.
- Pushover предоставляет 30-дневный пробный период, затем стоит 4,99 доллара за каждую платформу; автор оставил монитор собирать статистику, когда уведомления отключились.

## Как сделано
Автор описал задачу ChatGPT обычными словами, без специального мегапромпта. Поскольку публичную документацию API с данными о наличии топлива у Яндекса и Т-Банка найти не удалось, ИИ предложил изучить, как сайты загружают информацию, и получать данные из тех же источников. С помощью Codex автор написал на Python монитор, который проверяет выбранные АЗС каждые 10–15 минут. Для запуска использовал Android-смартфон, Termux — эмулятор терминала — и Pushover для уведомлений. В сообщения включил название и адрес заправки, наличие топлива в каждом источнике и время обновления.

Позже автор добавил журнал изменений статусов с фильтрами по АЗС и источнику. Примерно через месяц появилась открываемая в браузере карта на базе MapLibre: карточки показывают наличие АИ‑95, число подтверждающих источников и вероятные часы подвоза. Время подвоза оценивается по истории сообщений источников о появлении топлива.

## Результаты
Первую рабочую версию автор собрал примерно за час. Перед поездкой на 400 км уведомление сообщило о появлении бензина на выбранной заправке; автор приехал и заправился без очереди. После первой версии на доработки ушло не более двух часов, включая около получаса на карту. Монитор продолжает собирать и сохранять данные. Уведомления перестали приходить после окончания пробного периода Pushover.

## Ограничения
В статье не раскрыты конкретные сайты или технические детали получения данных, а также точность и надёжность источников и оценок времени подвоза. Успех описан на личном примере, без систематической проверки или сравнения с другими сервисами. Уведомления Pushover бесплатны первые 30 дней, затем подписка стоит 4,99 доллара за каждую платформу. Автор не сообщает, сколько времени монитор работает без сбоев и насколько часто источники обновляют сведения.

## Что взять себе
- Для небольшой личной автоматизации можно начать с описания задачи обычным языком и использовать ChatGPT и Codex для создания прототипа.
- Если готового публичного API нет, автоматизация может опираться на данные, которые сайты загружают сами, но надёжность и допустимость такого подхода стоит проверить отдельно.
- История наблюдений помогает выявлять закономерности, однако прогнозные часы подвоза — лишь оценка по прошлым сообщениям источников.
- Заранее проверьте стоимость сервиса уведомлений после пробного периода и предусмотрите альтернативу.
