## Коротко
Автор создал Lumi — бесплатное приложение с открытым исходным кодом для macOS и Windows, которое объединяет системный поиск файлов и запуск запросов к ИИ через одну горячую клавишу. Оно подключается к облачным моделям, официальным CLI-подпискам и локальным моделям; статья также описывает реализацию и совместную разработку с Claude Code.

## Контекст
Автор — независимый разработчик проекта Lumi, созданного вместе с ИИ-ассистентом Claude Code. Он хотел заменить рутинный переход от Spotlight или поиска Windows к отдельной вкладке браузера одной строкой для поиска файлов, запуска программ и вопросов моделям. Проект не связан с Anthropic, OpenAI или Google и распространяется под лицензией MIT.

## Главное
- Lumi — бесплатное приложение с открытым кодом под лицензией MIT для macOS и Windows; горячая клавиша — ⌥ Ё на Mac и Alt+Ё на Windows.
- Поиск использует системные индексы: Spotlight через `NSMetadataQuery` на Mac и Windows Search на Windows; собственного индексатора нет.
- Для подписок без отдельного API-ключа поддерживаются Claude Code, Codex CLI и Gemini CLI; автор утверждает, что Lumi не получает ключи и пароли аккаунта.
- Для OpenAI-совместимых API перечислены OpenRouter, OpenAI, DeepSeek, Groq, Mistral, YandexGPT и GigaChat; также поддерживаются Ollama и LM Studio.
- Для бесплатного доступа автор предлагает бесплатные модели OpenRouter, например `google/gemma-4-31b-it:free` и `nvidia/nemotron-3-super-120b-a12b:free`, либо локальный запуск через Ollama.
- Клиенты платформ написаны отдельно: Swift с AppKit и SwiftUI на macOS, C# с WPF и .NET 8 на Windows; Electron не использовался.
- Ответы от CLI обрабатываются как потоковые JSON-события, а от совместимых API — через Server-Sent Events; отдельная обработка нужна для ошибок, передаваемых внутри потока с успешным HTTP-ответом.
- Codex и Gemini запускаются в пустой папке в режиме только чтения, чтобы Lumi использовала их для ответов, а не для управления компьютером.
- Секреты хранятся в Связке ключей macOS или шифруются через DPAPI в Windows; в настройках на диске они не сохраняются.
- GitHub Actions собирает `.dmg`, установщик Inno Setup и portable `.exe` по тегу `v*`; Windows-сборку проверяет виртуальная машина, имитирующая нажатия и поиск.

## Как сделано
Lumi открывается сочетанием ⌥ Ё на Mac и Alt+Ё на Windows. Ввод текста показывает результаты системного поиска: macOS использует индекс Spotlight, Windows — меню «Пуск» и Windows Search. Для вопроса можно выбрать ответ ИИ; Enter отправляет вопрос, а ⌘↩ / Ctrl+Enter позволяет спросить модель даже при наличии найденных файлов. Уточнения продолжают диалог, Esc возвращает назад.

Пользователь может подключить Claude Code, Codex CLI или Gemini CLI после входа в соответствующий аккаунт; OpenAI-совместимые API, включая OpenRouter, OpenAI, DeepSeek, Groq, Mistral, YandexGPT и GigaChat; либо локальную модель через Ollama или LM Studio. CLI передают потоковые ответы через JSON: `claude -p --output-format stream-json`, `codex exec --json`, `gemini --output-format stream-json`. Codex и Gemini запускаются в режиме только чтения в пустой папке. Для совместимых API используются Server-Sent Events.

Приложение написано отдельно для каждой системы: macOS — Swift (AppKit + SwiftUI), Windows — C# (WPF, .NET 8). На Mac горячая клавиша регистрируется через Carbon `RegisterEventHotKey` для кодов Grave и Section. На Windows используется низкоуровневый клавиатурный хук и скан-код `0x29`, чтобы распознавать физическую клавишу на разных раскладках; нажатия Ctrl+Alt, используемые как AltGr, пропускаются. Ключи хранятся в Связке ключей macOS или шифруются DPAPI в Windows. Релизы собираются через GitHub Actions: тег `v*` запускает выпуск `.dmg`, установщика Inno Setup и portable `.exe`; Windows-сборку проверяет автотест в виртуальной машине.

## Результаты
Lumi заявлена как бесплатная программа для macOS и Windows с интерфейсом на русском, английском, немецком, испанском и французском языках. Она позволяет искать файлы и приложения, задавать вопросы разным облачным и локальным моделям из одного окна. В статье нет количественных результатов, сравнительных тестов производительности или данных о числе пользователей.

## Ограничения
Приложение пока не подписано сертификатами Apple и Microsoft, поэтому при первом запуске появляются предупреждения безопасности. Доступность Claude, ChatGPT и Gemini зависит от страны и сети; в статье отмечены ошибки 403 для пользователей из России, тогда как автор указывает на доступность Ollama, GigaChat и YandexGPT. Бесплатные модели OpenRouter могут отвечать с задержкой или пустым ответом. Для локальных моделей нужны подходящие ресурсы компьютера; для слабых устройств автор советует модели на 3–8 млрд параметров. Автор не приводит независимой оценки безопасности, производительности или качества ответов; Windows проверяется автотестом на виртуальной машине, а не на собственном компьютере автора.

## Что взять себе
- Одна оболочка может объединить системный поиск и доступ к нескольким ИИ-провайдерам, не заменяя системный индексатор.
- Для бесплатного использования можно выбрать бесплатные API-модели или запускать Ollama локально; локальный вариант не отправляет вопросы в интернет, но зависит от ресурсов компьютера.
- CLI существующих подписок и совместимые API — разные способы подключения: первый использует авторизацию в программе провайдера, второй требует адреса сервиса, ключа и названия модели.
- При разработке с ИИ-ассистентом полезны реальные пользователи и автоматизированные проверки: автор связывает с ними обнаружение ошибок в сообщениях о CLI и доступе по регионам.
- Проверьте предупреждения при первом запуске и доступность конкретного провайдера в своей стране; Lumi не устраняет региональные ограничения сам по себе.
