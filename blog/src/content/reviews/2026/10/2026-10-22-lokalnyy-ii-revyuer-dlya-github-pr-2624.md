## Коротко
Разработчик собрал бесплатный локальный инструмент, который проверяет изменения в GitHub PR и помогает быстрее находить ошибки, не отправляя код во внешние ИИ-сервисы.

## Контекст
Автор создал проект для утомительной первой проверки кода: при ручном просмотре изменений легко пропустить ошибки, особенно в конце рабочего дня.

## Главное
- Ревьюер делает первый проход по PR и оставляет комментарии с проблемами, объяснениями и возможными исправлениями; сам код не меняет.
- Модель работает локально через Ollama, поэтому diff не отправляется облачной ИИ-модели.
- В тестовом PR инструмент за примерно две минуты нашёл две ошибки, на которые автору обычно требовалось 15–20 минут первой проверки.

## Как сделано
Инструмент на Python отслеживает выбранные репозитории и новые или обновлённые PR. Он получает данные через GitHub REST API, передаёт diff локальной модели Qwen2.5-Coder через Ollama (`/api/chat` в режиме JSON), а затем публикует замечания в GitHub. Настройка модели и токена задаётся в `.env`: `OLLAMA_MODEL=qwen2.5-coder:3b` и `GITHUB_TOKEN= Your GitHub access token`. Для управления Python-зависимостями используется uv, конфигурацией — python-dotenv.

## Результаты
В тесте на PR об удалении заметок и поиске ревью появилось примерно за 2 минуты. Автор сообщает, что модель нашла две реальные ошибки: отсутствие очистки в `useEffect` и необработанные ошибки в `deleteNote`. Ручная первая проверка, по оценке автора, обычно занимает 15–20 минут.

## Ограничения
Это единичный тест на собственном демонстрационном репозитории, а не систематическая оценка точности. Автор отмечает, что локальная модель уступает самым сильным закрытым моделям. Утверждения о бесплатной работе и приватности относятся к описанной локальной конфигурации; сам проект всё равно использует GitHub для чтения PR и публикации замечаний.

## Что взять себе
- Локальную модель можно использовать для предварительного поиска ошибок, оставив человеку решения по архитектуре и дизайну.
- Перед использованием в рабочем процессе стоит проверять замечания модели: результат показан только на одном тестовом PR.
- Проект позволяет менять модель через настройку в `.env`, не переписывая остальную программу.
