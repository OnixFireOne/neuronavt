## Коротко
Команда Aigena выяснила, что Kling 4.0 при анимации фото без размеров сам выбирает более дорогой формат; передача ширины и высоты помогает сохранить выбранное качество и проверить расходы.

## Контекст
Авторы из команды агрегатора Aigena подключали Kling 4.0 через Runware и столкнулись с тем, что ролики из фото обходились дороже, чем показывалось пользователям.

## Главное
- Ошибки валидации помогли выяснить ограничения API до запуска генерации.
- Kling 4.0 может сам выбрать 1080p при работе с фото, если не передать ширину и высоту.
- Для исправления добавили отдельный флаг dimensions_with_frames, не меняя поведение остальных моделей.
- Проверять нужно не только изображение: авторы сверяли цену, размер, длительность, склейки и звук.

## Таблица
| Проверка | Что передали | Стоимость | Результат |
| --- | --- | --- | --- |
| Текст → видео | 1280×720, 3 с | $0.4004 | 1280×720 |
| Фото → видео | кадр без размеров, 3 с | $0.5993 | 1440×1440 |
| Фото → видео | кадр и 1280×720, 3 с | $0.4004 | 1280×720 |

## Как сделано
Сначала команда отправляла заведомо неверные запросы и использовала ответы валидации, чтобы выяснить допустимые параметры без запуска генерации. Затем сравнила короткие пробы текста и фото с размерами и без них. Для Kling 4.0 добавили настройку dimensions_with_frames: true, чтобы передавать размеры вместе с кадрами; для других моделей старую логику оставили. Перед запуском проверяли сочетания качества, пропорций и типа ввода. Готовые файлы проверяли командами ffprobe и ffmpeg, а речь — через распознавание Whisper.

## Результаты
Трёхсекундный ролик из фото без размеров стоил $0.5993 и получился 1440×1440; с размерами 1280×720 — $0.4004. Текстовый ролик 1280×720 также стоил $0.4004. По данным команды, фактическая цена 720p составляла $0.1335 за секунду против $0.157 в прайсе провайдера. Тестовые ролики прошли проверки речи, склеек и соответствия звука действию.

## Ограничения
Проверки описаны на примерах команды и не гарантируют одинаковое поведение во всех запросах. Документация провайдера сначала была неполной, поэтому параметры выясняли экспериментально. Русский отсутствовал в списке языков официального гайда; команда проверила его на одной фразе с помощью распознавания. Размеры из таблицы специфичны для модели: например, для квадратного 720p указан формат 940×940, а 960×960 не проходит.

## Что взять себе
- При подключении новой модели сначала проверяйте допустимые параметры и делайте короткие тесты.
- Сравнивайте фактическую стоимость API с ценой, показанной пользователю.
- Проверяйте итоговый видеофайл программно, а не только на глаз.
- Включайте модель для пользователей лишь после готовности кода и тестирования.
