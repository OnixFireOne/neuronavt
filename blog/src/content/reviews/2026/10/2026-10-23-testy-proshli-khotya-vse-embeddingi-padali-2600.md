## Коротко
Разработчикам AI-систем и тестов полезно проверять не только ответ детектора, но и факт вызова зависимости: так сбой API не маскируется под нормальный результат.

## Контекст
Автор описывает испытания agentwatch — инструмента безопасности для AI-агентов. В двух запусках API эмбеддингов возвращал ошибку 404, но тесты оставались зелёными, поскольку ошибка превращалась в None и трактовалась как отсутствие аномалии.

## Главное
- None обозначал сразу три разных случая: аномалии нет, проверка не удалась или модель вообще не вызывали.
- Сводка учитывала найденные аномалии, но отсутствие детектора в отчёте можно было принять за нулевое число срабатываний.
- Автор добавил чатовый запасной способ сравнивать тексты и записывать его в evidence как chat-fallback.
- Каждый тестовый сценарий теперь должен подтверждать, что модель действительно была вызвана.

## Таблица
| Зависимость | Значение при сбое | Как это выглядит |
| --- | --- | --- |
| LLM embed() | None | Аномалии нет |
| DB fetchrow() | None | Нет исходных данных |
| HTTP GET | "" | Нет данных |
| Cache get() | None | Нет в кэше |
| File read() | "" | Файл пуст |

## Как сделано
Вызовы эмбеддингов завершались ошибкой: сервер OMLX не предоставлял модель all-MiniLM-L6-v2. Автор добавил запасной путь: если векторы недоступны, чат-модель сравнивает два текста и возвращает оценку сходства от 0.0 до 1.0 по запросу: "Compare two texts and rate their semantic similarity on a scale of 0.0 to 1.0. Return only JSON: {"similarity": &lt;float>}". Расстояние считается как 1.0 минус сходство; первый вызов лишь задаёт исходный текст. В тестах теперь до и после каждого сценария снимаются счётчики chat_calls и embed_calls. Сценарий проходит только если был хотя бы один вызов модели: llm_called_ok = (llm_calls + embed_calls) > 0.

## Результаты
В одном прогоне все 98 вызовов эмбеддингов завершились ошибкой; в предыдущем — все 24. После исправления два сценария дали ожидаемые оценки: сходство 0.1 для разных текстов (аномалия обнаружена) и 0.95 для почти одинаковых (не обнаружена). Изменения включены в agentwatch v0.1.0.

## Ограничения
Чатовая оценка сходства грубее сравнения векторов. Она даёт модельное суждение, а не непрерывную метрику. Ошибки эмбеддингов 404 сохраняются, хотя запасной путь позволяет вынести вердикт. Первый текст задаёт базу и сам по себе не сравнивается.

## Что взять себе
- Проверяйте в тесте не только ожидаемый ответ, но и обращение к нужному сервису.
- Считайте отсутствие результата подозрительным, пока не доказано, что проверка выполнилась.
- Ошибки, влияющие на результат, превращайте в провал теста, а не оставляйте только в логах.
- Для отказавшей зависимости можно предусмотреть запасной путь, но явно отмечайте, каким способом получен результат.
